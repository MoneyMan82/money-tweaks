## Money Tweaks 1.4.1

Free, open-source Windows 10/11 performance and privacy tweaker. No accounts, ads, telemetry or paid tiers.

**New**
- **Presets**: built-in Competitive Fortnite, Low Latency, Stable FPS, Potato Graphics (Windows side) and Balanced Gaming,
  plus your own presets. Preview every change first, apply with backups and a restore point, and Undo reverts exactly
  what a preset changed. Import/export `.mtpresets.json` files.
- **Potato Graphics**: new Fortnite-style 3D illustration, and a "My Fortnite screenshots" mode to compare your own
  real before/after captures with the drag slider.

(v1.3.0 and v1.4.0 were the same build: the premium redesign and performance fixes. This release adds the two features
above, which weren't included in those tags.)

**Downloads**
- `MoneyTweaks-Setup.exe`: installer (per-user by default, no admin needed to install)
- `MoneyTweaks-1.4.1-portable-win-x64.zip`: portable, unzip and run `MoneyTweaks.exe`
- `MoneyTweaks-1.4.1-win-x64.exe`: the single-file app on its own
- `SHA256SUMS.txt`: verify with `Get-FileHash <file> -Algorithm SHA256`

**Notes**
- Not code-signed, so Windows SmartScreen may warn on first run: More info → Run anyway.
- Windows 10 1809+ or Windows 11, x64. The .NET runtime is bundled.
